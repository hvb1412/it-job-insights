# Quyết định và vấn đề cần chốt

## Quyết định đã ghi nhận ở mức kế hoạch
| ID | Nội dung | Lý do / phạm vi |
|---|---|---|
| D01 | Repository làm việc là it-job-insights | Cô lập phạm vi chỉnh sửa |
| D02 | Triển khai theo Lecture 2–8 | Giữ phụ thuộc và mốc đánh giá rõ |
| D03 | Python + FastAPI + React/TypeScript là kiến trúc đích | Pipeline, API và dashboard có trách nhiệm riêng |
| D04 | Phân biệt raw, dữ liệu sạch, artifacts và fixture | Truy nguyên và tái lập |
| D05 | Chỉ báo cáo kiểm tra và commit thực tế | Người nhận đánh giá được tiến độ |
| D06 | Lecture 8 chờ nội dung bài giảng | Chưa đủ cơ sở chọn công nghệ |

## Chưa chốt
- Thành viên, người điều phối, người review và người tích hợp.
- Phiên bản Python/Node/dependencies tương thích và được kiểm tra trên máy nhóm.
- Snapshot làm mốc, cách phân phối dữ liệu và metadata nguồn đầy đủ.
- Quy tắc xử lý chu kỳ lương chưa rõ và phiên bản cleaning được dùng.
- API contract chi tiết, giới hạn sample và phạm vi quality/metrics.
- Yêu cầu Lecture 8 và tiêu chí thử hiệu năng nếu có.
